# Workflow Engine Backend

Backend API for the Multi-Tenant Client Request & Approval Workflow Engine.

## Technology
- Node.js
- Express
- TypeScript
- PostgreSQL
- Prisma
- JWT

## Development

Install dependencies:

npm install

Create a local .env file using .env.example.

Start the development server:

npm run dev

Health check:

GET http://localhost:5000/api/v1/health
